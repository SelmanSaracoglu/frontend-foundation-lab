# Project 01: Course Directory

Covered modules: 01-04

## Goal

Build a small course directory that uses components, props, list rendering, and conditional rendering.

## Requirements

- Create a `CourseCard` component.
- Pass course data with props.
- Render the course list with `map`.
- Show whether each course is published or draft.
- Show an empty state when there are no courses.

## Files

- `starter.tsx`: fill this file first.
- `solution.tsx`: use this only after trying the starter yourself.
