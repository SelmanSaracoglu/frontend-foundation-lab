# Project 04: Auth Support Panel

Covered modules: 13-16

## Goal

Build a small authenticated support panel that combines auth UI state, RBAC, reusable components, and custom hooks.

## Requirements

- Login as viewer, support, or admin.
- Derive authentication state from `user`.
- Map roles to permissions.
- Show support actions based on permissions.
- Create reusable `Panel` and `ActionButton` components.
- Extract input and toggle behavior into custom hooks.

- `starter.tsx`: fill this file first.
- `solution.tsx`: use this only after trying the starter yourself.
