# Project 03: API Dashboard

Covered modules: 09-12

## Goal

Build a small dashboard that fetches API data, tracks request status, derives filtered UI, and renders safe fallbacks.

## Requirements

- Fetch post data from JSONPlaceholder.
- Model request state with `idle`, `loading`, `success`, and `error`.
- Map API data into a local `DashboardItem` type.
- Search items with derived UI.
- Render loading, error, empty, and success states.
- Use fallback text for optional fields.

## Files

- `starter.tsx`: fill this file first.
- `solution.tsx`: use this only after trying the starter yourself.
