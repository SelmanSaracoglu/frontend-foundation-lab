# Project 02: Searchable Feedback Board

Covered modules: 05-08

## Goal

Build a small feedback board that combines controlled inputs, form submit, callback props, and lifted state.

## Requirements

- Create a feedback form with controlled inputs.
- Store feedback items in the parent component.
- Search feedback with a controlled input.
- Pass state and callbacks through props.
- Render the filtered feedback list and an empty state.
